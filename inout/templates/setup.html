Set up this device

{% if not ready %}

Secure connections aren't set up on the server yet. On the server computer, run python manage.py make-certs and restart In-Out.

{% else %}

Do this once on each phone or computer. Afterwards In-Out opens with a normal padlock and no "Not secure" warnings.

1. Download the In-Out certificate

Download certificate

It only vouches for addresses on your local network. It can't be used for internet sites like your bank or email.

2. Trust it

iPhone / iPad
  1. Do the download in Safari (other browsers can't install it). Tap Allow.
  2. Open Settings, tap Profile Downloaded near the top, then Install (enter your passcode) and Install again.
  3. Go to Settings → General → About → Certificate Trust Settings and turn on In-Out Local CA.
Android
  1. Download the certificate above.
  2. Open Settings and search for CA certificate. It's usually under Security → More security settings → Encryption & credentials → Install a certificate.
  3. Tap CA certificate, then Install anyway, and pick In-Out-CA.crt from Downloads.
Windows
  1. Download and open In-Out-CA.crt, then click Install Certificate…
  2. Choose Current User, then Place all certificates in the following store → Browse → Trusted Root Certification Authorities.
  3. Click Finish, then Yes on the warning, and restart your browser.
Mac
  1. Download and open In-Out-CA.crt. Keychain Access opens.
  2. Double-click In-Out Local CA, open Trust, and set it to Always Trust.

3. Open In-Out securely
